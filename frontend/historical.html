⚡ First-time setup — connect Looker Studio to BigQuery

1
Run the export pipeline to push Gold marts to BigQuery:
python pipeline/export_to_bq.py  — this creates 5 tables in dataset ecom_gold
2
Go to lookerstudio.google.com → Create → Report → BigQuery → your project → ecom_gold
3
Build each chart in Looker Studio, then: File → Embed report → copy the <iframe> src URL (format: https://lookerstudio.google.com/embed/reporting/…)
4
Paste each URL into the LOOKER_URLS object at the bottom of this file, then reload. Placeholders will automatically become live iframes.
